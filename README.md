# Muzammil Khaliq — Personal Portfolio

A modern, premium, developer-focused personal portfolio website for **Muzammil Khaliq**, showcasing software development, AI/ML, data analytics, backend engineering, automation, and full-stack projects.

---

# 1. Project Vision

Build a portfolio that feels **custom-built, modern, professional, fast, secure, organized, and visually impressive**.

The website must communicate:

> **I don't just write code — I architect solutions.**

The portfolio should represent Muzammil as:

**Computer Science Graduate | Software Developer | AI/ML | Data & Automation**

It must NOT look like a generic portfolio template or agency website.

---

# 2. Core Objectives

The final website must be:

- Modern
- Professional
- Premium
- Fast
- Responsive
- Accessible
- Secure
- SEO-friendly
- Well-structured
- Easy to navigate
- Easy to maintain
- Eye-pleasing
- Performance optimized
- Mobile friendly
- Recruiter friendly
- Developer focused

Every section should have a clear purpose.

Avoid unnecessary content, excessive animations, visual clutter, and duplicated information.

---

# 3. FIRST: AUDIT THE EXISTING PROJECT

Before modifying anything:

1. Inspect the complete project structure.
2. Understand the existing React/TypeScript architecture.
3. Review all components.
4. Review styling and Tailwind configuration.
5. Review routes.
6. Review animations.
7. Review assets.
8. Review project/portfolio data.
9. Review GitHub and live links.
10. Review contact form and backend.
11. Identify duplicated or unused code.
12. Identify broken links and outdated content.
13. Identify console/build errors.
14. Identify existing security risks.
15. Identify reusable components.

Do not blindly rebuild the application.

Reuse good existing functionality where appropriate and refactor only where necessary.

---

# 4. DESIGN SYSTEM

## Visual Direction

Use an original design inspired by the provided developer/terminal reference image.

Design characteristics:

- Dark/near-black background
- Minimal technical aesthetic
- Terminal/code-inspired UI
- Monospace typography for technical elements
- Large modern typography
- Restrained green accent
- Subtle grid/dot background
- Thin borders
- Code/module-style cards
- Soft gradients
- Subtle glow effects
- Clean spacing
- Strong visual hierarchy
- Premium developer/SaaS feeling

Do NOT directly copy the reference image.

Create an original visual identity.
